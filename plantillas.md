# Plantillas de Prompts para Grok

Copia, pega y adapta estas plantillas según tu necesidad.

---

## 1. Análisis profundo y objetivo

```
Analiza [tema / problema] de forma exhaustiva y objetiva.

Estructura tu respuesta así:
1. Resumen ejecutivo (2-3 líneas)
2. Contexto actual (datos y hechos relevantes)
3. Fortalezas / Oportunidades
4. Debilidades / Riesgos
5. Análisis de trade-offs
6. Conclusión y recomendación clara (con nivel de confianza)

Sé directo. Señala dónde hay incertidumbre o falta de evidencia.
```

---

## 2. Revisión de código

```
Actúa como un senior engineer de xAI.

Revisa el siguiente código:

[pega tu código aquí]

Quiero:
1. Lista de problemas (bugs, seguridad, performance, legibilidad)
2. Código mejorado completo
3. Explicación breve de cada cambio importante
4. Sugerencias de tests si aplica

Sé técnico y directo. No suavices las críticas.
```

---

## 3. Generación de código desde cero

```
Escribe [descripción clara de lo que necesitas] en [lenguaje / framework].

Requisitos:
- [requisito 1]
- [requisito 2]
- [requisito 3]

Formato de respuesta:
1. Código completo y listo para usar
2. Explicación de las decisiones de diseño más importantes
3. Cómo usarlo / ejemplo de uso

Prioriza claridad, performance y buenas prácticas. Comenta solo lo necesario.
```

---

## 4. Comparación forzada (X vs Y)

```
Compara [opción A] vs [opción B] de forma brutalmente honesta.

Criterios:
- [criterio 1]
- [criterio 2]
- [criterio 3]
- [criterio 4]

Formato:
- Tabla comparativa clara
- Pros y contras de cada una
- ¿En qué casos elegir A?
- ¿En qué casos elegir B?
- Recomendación final (elige una y justifica)

No digas “depende” sin explicar exactamente de qué.
```

---

## 5. Critica + Mejora

```
Primero critica con dureza esta idea / propuesta / texto:

[pega aquí]

Luego dame una versión mejorada que resuelva los puntos débiles que encontraste.

Sé específico y constructivo, pero no suavices la crítica inicial.
```

---

## 6. Email / Mensaje profesional

```
Escribe un [tipo de mensaje: email frío / follow-up / propuesta / rechazo amable] para [audiencia].

Objetivo: [qué quiero lograr]
Tono: [directo / profesional / cercano / persuasivo]
Longitud: [corta / media]

Incluye:
- Asunto (si es email)
- Cuerpo del mensaje
- Call to action claro

Evita lenguaje genérico y frases vacías.
```

---

## 7. Explicación a diferentes niveles

```
Explícame [concepto / tema] en tres niveles:

1. Como si tuviera 12 años
2. Como para un profesional no técnico
3. Como para un experto del área

Sé preciso y evita simplificaciones incorrectas en el nivel experto.
```

---

## 8. Brainstorming estructurado

```
Necesito ideas para [objetivo / problema].

Genera:
- 8 ideas sólidas y realistas
- 3 ideas más arriesgadas / creativas
- 2 ideas “locas pero interesantes”

Para cada idea incluye:
- Descripción corta
- Por qué podría funcionar
- Principal riesgo o desafío

Prioriza calidad sobre cantidad.
```

---

## 9. Debugging / Resolución de problemas

```
Tengo este problema:

[describe el error o comportamiento inesperado]

Contexto:
- [tecnología / stack]
- [qué ya intenté]

Ayúdame a:
1. Diagnosticar las causas más probables (ordenadas por probabilidad)
2. Dar pasos concretos de depuración
3. Proponer la solución más limpia

Piensa paso a paso.
```

---

## 10. Opinión directa y sin filtro

```
Dame tu opinión más honesta y directa sobre [tema / decisión / idea].

No suavices. No uses eufemismos.
Si hay trade-offs claros, dímelos sin rodeos.
Si creo que algo es una mala idea, dímelo claramente y por qué.
```

---

## 11. Resumen ejecutivo + puntos clave

```
Resume el siguiente contenido:

[pega texto / artículo / documento]

Quiero:
- Resumen ejecutivo (máximo 5 líneas)
- 5-7 puntos clave en formato de lista
- Conclusión o takeaway principal

Sé conciso y preciso. Elimina relleno.
```

---

## 12. Plan de acción paso a paso

```
Quiero lograr [objetivo concreto].

Crea un plan de acción realista:
1. Pasos claros y secuenciales
2. Tiempo estimado por paso (si aplica)
3. Recursos o herramientas necesarias
4. Posibles obstáculos y cómo superarlos
5. Criterio de éxito (cómo sé que lo logré)

Sé práctico y específico.
```

---

## Cómo usar estas plantillas

1. Copia la plantilla que necesites
2. Reemplaza todo lo que está entre [corchetes]
3. Ajusta el tono o añade más contexto si es necesario
4. Si la respuesta no te convence, responde con:  
   “Mejora esta respuesta enfocándote en [qué quieres mejorar]”

---

**Consejo final:** Mientras más específico seas con el contexto y el formato deseado, mejor será el resultado.
